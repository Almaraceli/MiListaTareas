# Mi Lista de Tareas

Aplicación web sencilla desarrollada como parte de una actividad académica de UVEG sobre preparación, versionado y despliegue de aplicaciones web mediante un servidor Apache.

## Descripción

"Mi Lista de Tareas" permite al usuario registrar actividades pendientes, marcarlas como completadas, eliminarlas y limpiar las tareas que ya fueron terminadas.

La aplicación fue desarrollada utilizando tecnologías web básicas:

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Agregar tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Limpiar tareas completadas.
- Mostrar el número de tareas pendientes.
- Interfaz sencilla y adaptable.
